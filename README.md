📦 Barter Platform

Barter Platform — это веб-приложение для размещения объявлений о товарах и предложений обмена между пользователями.

🚀 Установка проекта

Клонируйте репозиторий:

git clone https://github.com/DonnieD-tech/barter_platform_test.git

cd barter_platform_test


Создайте виртуальное окружение и активируйте его:

python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

Установите зависимости:

pip install -r requirements.txt

Примените миграции:

python manage.py migrate

(Опционально) Загрузите тестовые данные в базу (если есть фикстуры):

python manage.py loaddata db.json

Запустите сервер:

python manage.py runserver

👥 Пользователи

Регистрация и авторизация пользователей.

Каждый пользователь может создавать, редактировать и удалять свои объявления.

📋 Основной функционал

Создание объявления с указанием названия, описания, категории, состояния и изображения.

Поиск объявлений по ключевым словам.

Фильтрация по категориям и состоянию товара.

Пагинация объявлений.

Предложение обмена между объявлениями разных пользователей.

Принятие или отклонение предложений обмена.

Страница "Мои обмены" с фильтрацией и статусами заявок.

🧪 Тестирование

Проект покрыт юнит-тестами для ключевых функций:

Создание объявления

Редактирование объявления

Удаление объявления

Поиск объявлений

Создание предложения обмена

Принятие предложения обмена

Отклонение предложения обмена

Запуск всех тестов:

python manage.py test
